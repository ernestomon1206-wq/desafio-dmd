&#x20;      **Desafío Práctico: Mercado Central de San Salvador (DMD404)**



**Descripción del Proyecto:**

Repositorio oficial del equipo para el desarrollo del análisis integral de datos del Mercado Central de San Salvador, abarcando el triaje EDA, Reglas de Asociación (Cross-Selling), Modelado Predictivo y Reflexión Ética.



**Estructura del Repositorio:**

&#x20; ***-***<i>'recursos/':</i> Contiene los archivos CSV oficiales     ('comerciantes\_mercado.csv', 'quiebra\_mercado.csv', 'transacciones\_mercado.csv').

&#x20; ***-***<i>'respuestas\_reflexion.md':</i> Análisis crítico sobre ética, privacidad y contexto económico salvadoreño.

&#x20; ***-***<i>'reporte\_final.pdf':</i> Documento ejecutivo de resultados (máximo 2 páginas, incluyendo el triaje EDA, resumen ejecutivo, estrategias y el grafo de red integrado).

&#x20; ***-**'src/':* Scripts y cuadernos de Python con el procesamiento y las visualizaciones de minería de datos.



**Instrucción de Ejecución:**

1\. Instalar las dependencias ejecutando en tu terminal: `pip install -r requirements.txt`

2\. Ejecutar los scripts para replicar las reglas de asociación y los modelos predictivos.
